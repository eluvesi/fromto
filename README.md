## Description
From To is a simple application for low-level network packet crafting and transmission.
It allows users to manually configure Ethernet, IP, TCP, UDP and ICMP headers and generate custom traffic.

## Installation
You can built flatpak using GNOME Builder:
1. Install [GNOME Builder](https://flathub.org/apps/org.gnome.Builder).
2. Click "Clone Repository" with `https://github.com/eluvesi/fromto.git` as the URL.
3. Click on the build button at the top.
